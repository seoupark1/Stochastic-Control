**What I implemented**
1) 기존에 tracking을 위해 필요한 reference 데이터를 body state 계산을 돌리며 같이 계산했었다. 이 방법의 문제점은 이미 다 알고 있는 reference attitude와 trajectory를 특정 t에 대해 그때그때 계산하니 불필요한 연산이 늘어난다는 것이다. 따라서 reference 데이터를 외부에서 가져오도록 하는 provider를 제작했다. 현재 코드는 reference 함수를 대입하면 mrp attitude, 각속도, 각가속도를 시간 t에 대해 get_reference 메소드를 통해 반환하는 형태이다. Provider 구조의 장점을 더욱 활용한다면 reference의 state를 csv 파일로 읽는 방식으로도 확장할 수 있다. 

2) Sensor에서 estimator, estimator에서 controller로 과정이 진행됨에 따라 각 장치들이 접근 불가능한 정보가 있다는 사실을 알게 되었다. 예를 들어, controller는 어떤 외란을 받는지 그 종류를 알지 못한다. 이 흐름을 깨달으니 원래 폴더 종류에 상관없이 상태벡터의 변수명을 'state'로 통일했었는데, controller에는 true state이 아닌 estimator에서 넘어온 'estimated_state'를 사용해야 한다는 사실을 알게 되어 수정했다.
